# מעשרותי — עשר תעשר, בשביל שתתעשר

מחשבון מעשרות לאנדרואיד ולאייפון: רושמים הכנסות ונתינות, והאפליקציה מחשבת כמה נשאר לתת. עובדת בלי אינטרנט, בלי הרשמה ובלי פרסומות.

## הורדה

**[הורדת האפליקציה (maasroti.apk)](https://github.com/luach-sport/maasroti/releases/latest/download/maasroti.apk)**

הקישור תמיד מוביל לגרסה האחרונה. הסבר מלא: https://luach-sport.github.io/maasroti/

### התקנה בטלפון
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ שירד. בפעם הראשונה הטלפון יבקש לאשר "התקנה ממקור לא ידוע". מאשרים.
3. בפתיחה הראשונה בוחרים מעשר או חומש, ומתחילים.

העדכונים הבאים נכנסים מתוך האפליקציה. הנתונים תמיד נשמרים.

### באייפון
**[פתיחת מעשרותי באייפון](https://luach-sport.github.io/maasroti/app/)** – פותחים בספארי, שיתוף ← "הוספה למסך הבית".

## מה יש באפליקציה
- **הכנסות:** מעשר, חומש או אחוז אחר בכל הכנסה, לפי הסכום נטו, עם ניכוי הוצאות.
- **הכנסות קבועות:** משכורת כל חודש ביום קבוע, עם תזכורת ו"נכנסה?" בלחיצה אחת.
- **נתינות:** למי, כבר נתתי או התחייבתי, צילום קבלה ומספר קבלה, סעיף 46.
- **קופת מעשרות:** כסף שהופרש בצד ועוד לא חולק.
- **נתינה מראש:** נשמרת כזכות ומקוזזת מההכנסות הבאות.
- **לאן אני נותן:** מקומות עם אחוזים, והצעה איך לחלק את מה שנשאר.
- **היסטוריה:** לפי חודשים עם תאריכים עבריים, ייצוא לאקסל ודוח שנתי לסעיף 46.
- **תזכורת שבועית**, גיבוי ושחזור, מצב בהיר / כהה, שיתוף האפליקציה ופנייה למפתח.
